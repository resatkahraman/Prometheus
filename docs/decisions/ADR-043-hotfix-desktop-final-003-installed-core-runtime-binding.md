# ADR-043: Installed Core Runtime Binding

Status: Accepted and validated

HOTFIX-DESKTOP-FINAL-003 replaces the release-only repository/Python lookup with an application-owned PyInstaller sidecar. Debug builds retain the canonical workspace Python launcher; release builds resolve the exact Tauri resource sidecar `prometheus-core-x86_64-pc-windows-msvc.exe` and use a writable application-data directory as its working directory.

The sidecar is generated by `scripts/build_desktop_core_sidecar.py` and is embedded through Tauri `externalBin` during the normal NSIS build. It binds only to loopback and preserves the existing authenticated, CSRF-protected Desktop transport and bounded Core lifecycle: explicit start/stop, one owned child, readiness timeout, and no auto-restart or arbitrary process authority.

The release runtime does not scan PATH, search for Python, depend on the Git checkout or write to installed resources. Ollama and local models remain external and are not bundled. The 0.1.3 development installer is unsigned; code signing and updater infrastructure remain future release work.

Validation: sidecar smoke readiness passed from a non-repository working directory; targeted tests 9 passed; Rust tests 17 passed; `cargo check`, `npm ci`, frontend build and NSIS build passed. The generated installer is `Prometheus_0.1.3_x64-setup.exe`, SHA-256 `A8A2DCFBCB26DB9CE85961CD5AE9D7786B1B897E6FB2AD758BAF915C437CBE82`, and is `NotSigned`.
